Reading a Micrometer (inches)

  1. Zero-check: close on the anvil with the ratchet. Reads 0?
  2. Clean the part. Let it cool. Close with the ratchet, 2 to 3 clicks.
  3. Sleeve number = 0.100 each (7 = 0.700).
  4. Small sleeve lines past it = 0.025 each.
  5. Thimble line on the datum line = 0.001 each (0 to 24).
  6. Add them: 0.700 + 0.000 + 0.008 = 0.708.
  7. Vernier: the vernier line that lines up = 0.0001 each.
  8. 1-2 in mic: add 1.000.

Reuse if inside the limits. Re-measure if close to reject. Replace if at or past reject.
