Why the full number matters

Briggs and Stratton builds many versions of the same basic engine. The model tells the engine family. The type tells the exact version (shaft, mounting, options, who it was built for). The code tells when it was built. Parts can change between types and even between build dates, like the flywheel on this engine. That is why the IPL lookup on briggsandstratton.com asks for all three.
